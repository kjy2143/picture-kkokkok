# 오답 효과음 개선

차이가 없는 곳을 눌렀을 때 나는 소리를 개선한다. 사용자는 올라가는 두 음을 선택했다. 어린이에게 부담을 주지 않는 짧고 부드러운 소리라는 PRD 요구사항을 따른다.

## 접근 방식

기존 180Hz 단음을 부드럽게 다듬는 방식과 올라가는 두 음으로 바꾸는 방식을 고려했다. 사용자 선택에 따라 두 음으로 바꾼다. 정답 효과음과 구분하도록 낮은 음역을 사용한다.

## 구현 결정

기존 Web Audio 합성 방식을 유지한다. 220Hz와 261.63Hz를 75ms 간격으로 재생한다. 각 음은 140ms 동안 이어지며 최대 음량은 0.028이다. 시작 음량은 18ms 동안 올린다. 수치는 구현 담당자의 선택이며 실제 iPad 청취 검증 후 조절할 수 있다.

정답·완료 효과음, 음소거 저장, 게임 콘텐츠는 변경하지 않는다. 공개 배포는 수행하지 않는다. 자동 검사로 재생 호출을 검증하며 실제 iPad의 청감 검증은 별도로 남긴다.
