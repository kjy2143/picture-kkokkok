## 구현 선택

검증한 빌드를 다시 만들면 기기 검증과 파일 해시가 달라질 수 있으므로 `deploy`는 빌드를 재실행하지 않는다.
`build`로 후보를 만들고 그 파일을 검증한 뒤 `deploy`한다.
미승인 제작 중 결과는 `work/content`에서 보존하며 완성된 게임만 `stage`로 등록한다.
첫 공개에 18개를 검사한다. 이후 콘텐츠 추가를 18개로 제한하지 않는다.
파일 승인과 플레이 진행 버전은 별개다. metadata 수정은 재승인이 필요하지만 정답 위치·그림이 같으면 진행 기록은 유지한다.
