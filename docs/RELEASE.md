# 가족 전용 배포와 복구

등록된 콘텐츠 전체를 빌드한다. 별도 검수 승인 절차는 없다. 아래 기기 확인은 권장 품질 확인이며 배포를 막는 수동 확인 단계가 아니다.

2026-10-29 사용자 선택에 따라 웹 배포 서비스는 가족 전용이다. 콘텐츠 검수 승인과 별개로, 무인증 사용자가 앱·게임 파일을 받을 수 없도록 배포 경로를 보호해야 한다. 배포 예정 기본 주소에 Cloudflare Access 애플리케이션과 단일 부모 이메일 허용 정책을 등록했다. 실제 앱 배포·부모 로그인·기기 검증은 수행하지 않았다.

## 가족 전용 접근 보호

Cloudflare Workers Static Assets 앞에 Cloudflare Access를 적용한다. 부모의 정확한 이메일 주소를 허용 목록에 등록하고 이메일 일회용 코드로 인증한다. 아이의 계정은 만들지 않는다. 정책의 이메일 목록은 Cloudflare에서 관리하며 저장소나 배포 파일에 넣지 않는다.

현재 기본 주소 `picture-kkokkok.jooa-bingo.workers.dev`에 호스트 이름 단위 보호를 등록했다. 애플리케이션과 정책 세션은 1주이며 이메일 일회용 코드만 사용한다. 허용 이메일과 원격 설정 식별자는 Git에서 제외되는 `work/deployment/family-access.json`에 보관한다.

`wrangler.jsonc`는 해당 계정을 지정하며 `preview_urls: false`로 미리보기를 비활성화한다. 호스트 이름 단위 보호이므로 사용자 도메인·미리보기 주소를 추가하기 전에 별도 보호 또는 Worker 단위 `All traffic` 보호를 적용해야 한다.

첫 업로드 전에 Zero Trust와 허용 정책을 확인한다. 계정 단위 Worker `All traffic` 보호 또는 배포 접근 경로 비활성화 등으로 첫 업로드 중에도 무인증 접근이 열리지 않는 순서를 확보한다. 계정 전체 보호는 다른 Worker에도 영향을 주므로 기존 서비스를 먼저 확인한다. 이후 대상 Worker의 `All traffic` 보호로 범위를 관리한다.

앱 기본 주소뿐 아니라 사용자 도메인·미리보기 주소·이미지·정답 JSON을 모두 보호한다. 정책에 전체 이메일 도메인이나 모든 사용자 허용 규칙을 넣지 않는다.

`npm run deploy`와 `--dry-run`은 로컬 산출물 검사만 수행한다. 원격 Access 보호나 이메일 허용 정책이 설정됐다는 증거가 아니다. 다음 사항은 실제 환경에서 확인해야 한다.

- 미인증 환경에서 운영·미리보기 주소와 JS·`catalog.json`·게임 이미지·`puzzle.json` 직접 요청 차단
- 허용한 부모 이메일의 로그인 성공과 허용하지 않은 이메일의 접근 차단
- Safari·홈 화면 PWA 각각의 첫 로그인·세션 만료·재로그인과 인증 경로의 Service Worker 제외
- 인증 후 저장한 게임의 오프라인 실행과 미저장 게임 다운로드 시 인증 요구

저장한 게임은 세션 만료·권한 취소 후에도 기기에서 실행할 수 있다. Access는 이후 서버 요청을 제한하며 기기 파일을 원격 삭제하지 않는다. 애플리케이션과 정책 세션은 1주로 설정했다. Service Worker가 `/cdn-cgi/access` 경로를 앱 화면으로 가로채지 않도록 제외했다. 만료 안내와 실제 기기 재로그인 동작은 아직 구현·검증하지 않았다.

## 빌드와 배포

1. `npm test`와 `npm run build`로 등록된 게임 전체를 빌드한다.
2. `npm run release:check`로 목록·파일 해시·산출물과 기본 주제·난이도 구성을 자동 검사한다.
3. `npm run deploy -- --dry-run`으로 업로드 없이 배포 검사를 실행할 수 있다.
4. 위 접근 보호를 준비하고 사용자가 배포를 요청한 경우에만 `npm run deploy`로 업로드한다.

게임별 승인 명령과 실제 기기 확인 기록은 필요하지 않다. 과거 `reviews/` 기록은 빌드·배포 판단에 사용하지 않는다. 빌드 후 콘텐츠나 목록이 바뀌면 자동 검사가 실패하므로 다시 빌드한다.

## 권장 실제 기기 확인

- Safari에서 설치 없이 실행, 홈 화면 추가 후 독립 실행
- 손가락·Apple Pencil의 양쪽 정답 선택과 재터치 중복 방지
- 가로·세로 배치, 회전 시 정답 유지, 두 손가락 확대·이동
- 힌트 주변 강조, 자동 정답 처리 없음, 오답 표시·무감점·오답 효과음
- 완료 화면의 버튼, 다시 풀기, 효과음 켜기·끄기 저장
- 앱 종료·재실행 후 이어 풀기
- 열어본 게임의 오프라인 실행, 미저장 게임 안내, 오프라인 파일 삭제 후 기록 유지
- 기록 초기화의 확인 단계
- 실제 새 빌드 준비 후 플레이 도중 버전 유지, 홈에서 안내, 저장 후 버튼 업데이트
- 제목·썸네일 변경 후 진행 유지, 그림·정답 위치 변경 후 해당 게임만 초기화
- 주아가 직접 플레이했을 때 조작·판정 때문에 진행하지 못하는 문제가 없음

## Cloudflare 직접 배포

Wrangler 로그인은 Mac에서 진행한다. 인증 정보를 저장소에 저장하지 않는다.

```sh
npx wrangler login
# 가족 접근 보호를 준비한 뒤 자동 검사한 dist를 배포한다.
npm run deploy
```

Wrangler의 배포 출력에서 Cloudflare 버전 ID를 보존한다. `work/releases/<releaseId>.json`에도 배포한 콘텐츠 목록을 기록한다. 배포 후 실제 주소에서 미인증 접근 차단과 가족의 홈·게임 접근을 확인한다.

## 복구

이전 정상 버전의 Cloudflare 버전 ID를 확인한다.

```sh
npx wrangler deployments list
npx wrangler rollback <이전-정상-버전-ID>
```

명령은 실제 공개 서비스에 영향을 준다. 문제 발생 시 정상 버전 ID를 확인한 뒤 수행한다. 기기의 진행 기록과 소리 설정은 일괄 삭제하지 않는다.

서버가 복구돼도 기존 PWA가 즉시 바뀌는 것은 아니다. 홈에서 업데이트 안내·적용을 확인한다. 같은 서비스 워커로 복구가 감지되지 않으면 정상 코드·콘텐츠를 새 releaseId로 빌드·검증해 재배포한다. 게임 버전은 파일 내용 기준이므로 제목 변경만으로 진행 기록을 초기화하지 않는다.

업데이트 도중 새 파일을 받지 못하거나 진행 기록 저장이 실패하면 현재 버전에서 머물며 다시 시도한다. 자동 생성·검수는 기기 데이터가 영구 보관된다는 보장이 아니다.
