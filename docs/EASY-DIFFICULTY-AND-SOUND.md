# 쉬움 난이도와 효과음 조정

2026-10-14 요청을 2026-10-15에 반영했다. 난이도 조정 범위는 사용자 선택에 따라 최근 만든 4:5 세로 게임 `animals-easy-picnic-portrait` 한 개다. 기존 쉬움 게임 6개는 교체하지 않았다. 게임 수와 정답 수는 19개·157개를 유지한다.

## 효과음

정답·완료의 기존 효과음을 유지한다. 오답에는 180Hz, 140ms의 작고 낮은 소리를 추가했다. 오답 표시와 감점 없는 동작도 유지한다. 처음 실행하는 기기는 소리가 켜진다. 사용자가 명시적으로 저장한 음소거 설정은 유지한다. 소리를 끄면 정답·오답·완료 모두 재생하지 않는다.

Web Audio는 실제 입력 이벤트에서 생성·resume한다. 브라우저의 재생 제한이나 기기의 음량·음소거 상태까지 자동 검증으로 보장하지 않는다. 실제 iPad의 소리 크기와 느낌은 확인하지 않았다.

## 정답 구성

2026-10-15 추가 요청에 따라 색깔·표정·개수 차이를 함께 넣었다. 정답은 7개를 유지한다. 판정 영역을 작게 줄여 난이도를 높이지 않는다.

## 버전과 검수

Codex 내장 이미지 도구로 원본을 참조해 변경 그림을 새로 편집했다. 이전 색 차이 버전은 `work/content/animals-easy-picnic-portrait/color-v1/`와 `work/archive/`에 보존했다. 이전 모양 중심 버전은 `work/content/animals-easy-picnic-portrait/shape-v2/`에 보존했다. 현재 생성 원본과 계획·프롬프트는 `work/content/animals-easy-picnic-portrait/mixed-v3/`에 있다. 현재 게임 파일은 `content/games/animals-easy-picnic-portrait/`다.

변경 그림과 표정·발바닥 정답 영역이 바뀌어 이 게임의 진행 버전만 변경된다. 다른 18개 게임의 그림·정답 데이터는 바꾸지 않았다. 콘텐츠 승인과 공개 배포는 하지 않았다.

현재 미승인 검수 후보다. 7개 혼합 유형 차이를 육안으로 확인했다. 생성 그림의 미세한 질감·윤곽 차이가 완전히 없다는 증명은 아니다.

## 현재 버전의 로컬 확인 (mixed-v3)

타입 검사와 19개 콘텐츠 검사가 통과했다. 단위 테스트 13개와 Chromium·WebKit 브라우저 테스트 6개가 통과했다. 전체 19개 게임의 정답 157개 판정, 세로 게임의 화면 배치·다시 풀기·저장을 확인했다. 다른 18개 게임 파일 91개의 해시는 변경되지 않았다. 실제 iPad와 아이의 체감 난이도는 확인하지 않았다. 검증 기록은 `docs/verification/mixed-differences.json`에 있다.

## 이전 버전의 로컬 확인 (shape-v2)

타입 검사·19개 콘텐츠 검사·빌드·단위 테스트13개를 통과했다. Chromium·WebKit 브라우저 검사15개를 통과했으며 WebKit의 CDP 터치 주입1개는 기존 정책대로 제외했다. 소리 기본값·오답과 정답의 서로 다른 재생 호출·저장된 음소거 유지, 19개 게임157개 정답과 완료·이어 풀기·오프라인·확대를 확인했다. 실제 기기에서 소리를 듣거나 아이의 체감 난이도를 확인한 결과는 아니다. 검증 기록은 `docs/verification/easy-difficulty-and-sound.json`에 있다.
