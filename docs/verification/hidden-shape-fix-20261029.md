# 숨은그림 물건 형태 개선 결과 — 2026-10-29

**19개 게임의 목표 35개를 개선했다.** 이전 검토의 수정 필요 18개와 추가 확인 대상 17개를 모두 처리했다. 장면 18장과 목표 카드 35개를 교정했다. ‘다람쥐의 도토리 집’은 장면을 보존하고 카드만 바꿨다. 물건 이름과 정답 ID·개수는 유지했다.

수정한 게임의 전체 목표 157개를 최종 장면·카드·정답 표시 이미지로 다시 확인했다. 기존 틀린그림찾기 30개와 이번 대상에 포함되지 않은 숨은그림 11개의 콘텐츠 파일은 SHA-256으로 보존을 확인했다. 전체 등록 수는 60개이며 숨은그림은 30개·목표 250개다.

## 지적한 아침 식탁

- 종: 전등갓 자체를 종으로 간주하던 상태를 버리고 갓 표면의 무늬 안에 고리·몸통·벌어진 입구·종추를 가진 종을 만들었다. 카드도 그 종 윤곽에 맞췄다.
- 나비: 커튼의 긴 리본 끈을 없애고 몸통·더듬이·큰 윗날개 두 장·작은 아랫날개 두 장으로 교정했다.
- 숟가락: 의자 무늬의 왼쪽 끝은 가느다란 손잡이, 오른쪽 끝만 뜨는 부분으로 만들었다.

## 확인한 내용

- 35개 목표의 핵심 구조와 장면·카드의 주요 윤곽을 대조했다. 색·재질 차이는 허용하며 방향과 부품 수를 임의로 바꾸지 않았다.
- 수정한 19개 게임의 전체 목표 157개와 최종 판정 영역을 검수했다. 장면 변경으로 위치가 바뀐 종·나비·초승달·왕관·활 등은 좌표를 다시 잡았다.
- 목표 PNG는 실제 투명도를 검사하고 흰 배경과 카드 배경에 합성해 확인했다. 알파가 0인 픽셀에 남은 RGB 값은 실제 배경으로 취급하지 않았다.
- `npm run build`: 60개 게임 데이터 검사·내보내기·배포 산출물 검사 통과.
- `npm test -- tests/hidden-content.test.ts`: 5개 통과.
- `npx playwright test tests/browser/hidden.spec.ts`: 12개 통과. Chromium·WebKit에서 숨은그림 30개·250개 정답의 선택과 완료, 저장·힌트·반응형 배치·오프라인 복원을 검사했다.

실제 iPad A16·Apple Pencil 입력과 주아의 식별·체감 난이도는 확인하지 않았다. 공개 배포는 수행하지 않았다.
