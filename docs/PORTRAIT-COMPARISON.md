# 4:5 세로 게임과 놀이 화면 비교

2026-10-15 후속 조정: 같은 게임 ID의 색 차이 버전을 형태·무늬·개수·유무 중심으로 교체했다. 현재 정답 구성과 효과음은 [쉬움 난이도·효과음 조정](EASY-DIFFICULTY-AND-SOUND.md)을 따른다. 아래 색 차이 목록은 첫 비교용 버전의 기록이며 `work/content/animals-easy-picnic-portrait/color-v1/`에 보존했다.

2026-10-14 사용자 요청으로 동물 쉬움 게임 1개를 4:5 세로 구도로 추가했다. 게임 ID는 `animals-easy-picnic-portrait`, 제목은 `키 큰 나무 아래 소풍`이다. 기존 초기 18개는 보존했다. 새 게임은 미승인 검수 후보이며 공개 배포하지 않았다.

## 비교 결과

1180×820 CSS px 브라우저에서 실제 렌더링을 측정했다. 상단은 뒤로가기·제목·진행·전체 보기·힌트·소리·도움말을 64px 한 줄로 묶었다. 놀이 중 브랜드 헤더와 검수 배너는 표시하지 않는다. 홈에서는 검수 상태를 안내한다.

| 구성               | 그림 한 장 | 두 그림의 화면 면적 |
| ------------------ | ---------: | ------------------: |
| 기존 UI · 3:2 가로 |    558×372 |               42.9% |
| 새 UI · 3:2 가로   | 566×377.33 |               44.1% |
| 새 UI · 4:5 세로   |  566×707.5 |               82.8% |

새 세로 그림의 면적은 기존 UI의 가로 그림보다 약 1.93배다. 화면 높이가 720px이면 486.39×607.98px로 줄어들며 화면 안에 들어간다. 기기를 세로로 놓으면 위아래 배치를 유지한다. 세로 iPad와 휴대폰에서 상단은 필요한 만큼 줄바꿈한다.

이미지 크기는 1120×1400이다. Codex 내장 이미지 도구가 반환한 원본을 가장자리 자르기 없이 정확한 4:5 크기로 소폭 리사이즈했다. 원본·변경 그림은 이미지 도구에서 제작했다. 코드로 게임 그림의 색이나 사물을 편집하지 않았다. 생성 프롬프트·계획은 `work/content/animals-easy-picnic-portrait/`에 보존했다.

## 폰트와 레이아웃

나눔스퀘어라운드 Regular(400)·Bold(700)를 네이버 공식 웹폰트에서 가져와 `src/assets/fonts/`에 저장했다. 외부 CDN을 런타임에 호출하지 않는다. 두 파일과 라이선스는 서비스 워커 사전 캐시에 들어간다. 제목과 놀이 도구는 실제 Bold를 사용한다.

보드는 각 게임의 `width/height`를 비율로 사용한다. 남은 화면의 폭·높이에 동시에 맞추며 그림을 자르지 않는다. SVG 박스 비율과 viewBox 비율을 같게 유지해 정답·확대 좌표가 일치하도록 했다. 기존 게임의 정답 데이터와 힌트 시간을 바꾸지 않았다.

## 검증

- 타입 검사와 19개 콘텐츠 데이터 검사 통과.
- 단위 테스트 13개 통과.
- Chromium·WebKit 브라우저 테스트 13개 통과. WebKit의 CDP 터치 주입 테스트 1개는 기존 정책대로 제외.
- 19개 게임의 정답 157개를 양쪽 번갈아 눌러 완료까지 확인.
- 새 세로 게임의 비율·화면 넘침·가로 상단 64px·가장자리 정답 좌표·힌트 검사 통과.
- 마지막 가운데 간격 수정 후 Chromium·WebKit 관련 검사 5개를 다시 통과했다. 두 가로 화면 높이에서 실제 그림 사이 16px 간격을 확인했다. WebKit CDP 검사 1개는 제외했다.
- 기존 게임의 이어 풀기·오프라인·업데이트·동기 확대 검사 통과.
- 공개 빌드 및 산출물 검사 통과. 승인 게임이 없으므로 공개 카탈로그는 0개다. 배포하지 않았다.
- 화면 캡처의 JavaScript 실행 오류 0건. 자동 디자인 검출 0건.

실제 iPad A16의 Safari·설치 PWA·Pencil·아이 플레이는 확인하지 않았다. 새 세로 구도는 가로 모드에 유리하며, 세로 모드에서는 그림 두 장을 위아래로 맞추면서 폭이 줄어든다.
