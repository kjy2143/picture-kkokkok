# 가로 모드 비교용 콘텐츠 재생성

> 2026-10-28: ‘키 큰 나무 아래 소풍’은 사용자 요청으로 목록에서 제거했다. 현재 목록은 18개 게임·150개 정답이다. 아래는 변경 전 제작·검증 기록이다.


2026-10-15 사용자 정정에 따라 기존 가로 게임 18개를 삭제하고 4:5 세로 그림으로 새로 제작했다. ‘키 큰 나무 아래 소풍’은 유지했다. 가로 모드에서는 세로 그림 두 장을 좌우에 배치한다.

## 결과

- 동물·우주·공주·동화·교통·일상 각각 쉬움·보통·어려움 1개를 새로 제작했다.
- 새 그림 36장과 유지한 시범 2장을 포함해 19개 게임·157개 정답을 제공한다.
- 모든 원본·변경 그림은 1120×1400이며 원본을 자르지 않고 표시한다.
- 새 게임마다 색깔·표정·개수·모양·무늬·유무를 섞어 7·8·10개 차이를 계획했다.
- 기존 가로 파일은 활성 콘텐츠에서 제거했다. 제작 이력은 `work/archive/landscape-before-portrait-20261015/`에 보존했다.

게임 ID와 제목·난이도는 유지했다. 새 그림과 정답 영역으로 교체한 18개는 진행 버전이 달라져 처음부터 시작한다. 유지한 세로 시범의 그림·정답·metadata·썸네일은 변경하지 않았다.

## 검수

생성한 원본을 확인한 뒤 차이를 계획했다. 변경 그림에서 계획한 차이와 의도하지 않은 변경을 확인했다. 발바닥 무늬, 컵케이크 개수, 모자 밖의 무늬, 달팽이 표정, 팔찌 장식, 탐사차 지지대 색 등의 문제는 재편집했다. 공주 찻집은 원본에서 다시 편집해 컵케이크 5개와 4개를 만들었다.

최종 좌표를 실제 그림에 맞췄다. 새 게임의 타원 정답 영역은 중심 검사와 경계 360방향 표본 검사에서 다른 정답과 겹치지 않았다. 이는 표본 검사 결과이며 이미지의 의미나 생성 질감까지 자동으로 증명하지 않는다.

| 검사                      | 결과                                  |
| ------------------------- | ------------------------------------- |
| 타입·콘텐츠               | 19개 게임 통과                        |
| 단위 테스트               | 13개 통과                             |

실제 iPad A16·Apple Pencil·아이의 체감 난이도는 확인하지 않았다. 부모의 콘텐츠 승인과 공개 배포는 수행하지 않았다. 자동 검사와 제작자 이미지 확인을 부모의 승인으로 기록하지 않았다.
